# Локальна перевірка швидкодії

22 вересня 2026. Порівняння production-збірки до розширення контенту та оптимізації зі збіркою після цих змін, до додавання редагованих описів фото галереї. В обох уже є SSR і лише одна публічна сторінка. Наведені розміри та заміри фіксують ці дві збірки; подальші зміни коду можуть змінювати їх.

## Зміни

- Framer Motion видалено: видимі блоки не потребують анімаційної обгортки, паралакс фото використовує браузерні API. На мобільних, у фоновій вкладці та при зменшенні руху зайва робота не виконується.
- Manrope і Cormorant Garamond роздаються із сайту у WOFF2 з `unicode-range` та `font-display: swap`. Зовнішній запит CSS Google Fonts прибрано. [Джерела й ліцензії](../src/assets/fonts/README.md).
- Фото першого екрана отримало варіанти 480×600 (18 158 B) і 800×1000 (36 016 B); оригінал 1200×1500 (69 870 B) збережено. `sizes` відповідає ширині фото в CSS. DPR3 на вузькому екрані може потребувати оригінал; зменшення трафіку залежить від пристрою.

| Ресурс | До | Після |
|---|---:|---:|
| Основний JS, без стиснення | 445 843 B | 321 705 B |
| Основний JS, gzip через Node zlib | 142 209 B | 102 375 B |
| Основний CSS, без стиснення | 26 070 B | 33 240 B |

JS зменшився приблизно на 28%, включно з новими текстами. CSS зріс через локальні `@font-face` та стилі пояснень. Файли шрифтів і решта ресурсів не входять до розміру JS; це не зменшення всього сайту на 28%.

## Лабораторні результати

Chromium 153.0.8010.12, 390×844, DPR3, CPU ×4, 1,6 Мбіт/с, затримка 150 мс. Локальний HTTP-сервер із gzip, початкові публічні дані, новий браузерний контекст і вимкнений кеш для кожного запуску. Три запуски на варіант, у таблиці медіани. Карта за межами першого екрана заблокована. Зовнішні шрифти старої версії завантажувалися успішно; нова версія отримувала їх локально.

| Метрика | До | Після |
|---|---:|---:|
| Перший видимий вміст, FCP | 736 мс | 576 мс |
| Найбільший видимий елемент, LCP | 1 636 мс | 1 728 мс |
| Сума зсувів під час початкового завантаження | 0,000067 | 0,000067 |

Перший вміст з’явився раніше, але цей замір **не підтвердив покращення LCP**: фото було готове на 92 мс пізніше. На DPR3 браузер обрав оригінальне фото. Локальний HTTP і запити до Google Fonts мають різні умови з’єднання та пріоритети; самостійна роздача шрифтів не гарантує прискорення кожної метрики. Потрібна перевірка після розгортання на реальному CDN. [web.dev: завантаження шрифтів](https://web.dev/articles/font-best-practices).

Це не PageSpeed score, польові Core Web Vitals чи вимірювання INP. Початкова сума зсувів не охоплює всю сесію користувача. Результати не доводять зміну позицій у Google.

## Повторення

```bash
npm run build
npm run perf -- --runs=3 --output=/tmp/beauty-performance.json
```

Скрипт піднімає тимчасовий сервер на вільному порту, використовує публічні початкові дані й закриває сервер та браузер після перевірки. Встановлений Chromium для Playwright потрібен. Для порівняння з попередньо збереженою SSR-збіркою можна передати `--assets=/path/to/captured-dist --label=before`; її `index.html` має містити вже відрендерений контент відповідної версії.

Після публікації перевірити PageSpeed Insights і доступні польові LCP, INP та CLS. Порівнювати однакові умови й кілька запусків, а не один найкращий результат.
