# SEO Beauty Space Victoriya

Аудит: 22 вересня 2026. Сайт: https://victoriya-beauty.space/. Конкурент: https://sofia-nails.kiev.ua/.

Сайт залишається односторінковим: послуги, прайс, роботи, відгуки й контакти розміщені на головній. Окремі сторінки послуг прибрано за рішенням власника. Вони не були опубліковані; їхні адреси не додаються до sitemap чи розмітки та повертають 404 на сервері.

Основний локальний запит — **«манікюр ЖК Софія»**. Манікюр має найвищий пріоритет, педикюр — другий, фактично доступні послуги для вій — третій.

| Пріоритет | Група запитів | Зміст головної |
| --- | --- | --- |
| 1 | манікюр ЖК Софія; манікюр Софіївська Борщагівка; манікюр Вишневе | Title, видимий H1, прайс, пояснення варіантів манікюру, фото робіт і локальний блок |
| 2 | педикюр ЖК Софія; педикюр Софіївська Борщагівка; педикюр Вишневе | Прайс, склад процедур, локальний H2 та FAQ з актуальними цінами |
| 3 | ламінування та фарбування вій із відповідними локальними уточненнями | Описи реально доступних послуг і роботи; нарощування вій як повна процедура не заявляється |

Title і description зберігають основний акцент на манікюрі для мешканців ЖК «Софія». Вишневе згадується як напрямок приїзду до фактичної адреси у Софіївській Борщагівці. Це не окрема філія і не твердження про розташування всередині комплексу. При зміні населеного пункту в адмінці локальні згадки ЖК «Софія» й Вишневого прибираються автоматично. Окремі сторінки під варіанти запиту не створюються. У текстах використовується нормативне «педикюр»; варіант «педікюр» можна враховувати під час аналізу фактичних запитів.

## Що покращено

- Повний React SSR замість порожнього root і контенту тільки в `noscript`. Прайс, контакти та галерея доступні у звичайному HTML до завантаження JavaScript.
- Сервер і браузер починають з одного опублікованого snapshot, після чого React гідратує сторінку. Ціни в UI та JSON-LD оновлюються зі спільного провайдера.
- Великий слоган «Краса починається з любові до себе» оформлено як текстовий блок. Під ним розміщено один видимий H1 «Манікюр для мешканців ЖК «Софія»» читабельним шрифтом 18 px на комп’ютері та 16 px на мобільному. Фактична адреса залишається у першому екрані. Відвідувачі й пошуковики отримують однаковий вміст; текст для пошуковика не приховується. Google може враховувати і великий слоган, і H1 при виборі заголовка результату — сама HTML-ієрархія не гарантує потрібного заголовка чи позицій. [Google: заголовки результатів](https://developers.google.com/search/docs/appearance/title-link). Прайс використовує native details і відкривається без JavaScript.
- На головній усі шість категорій отримали конкретні описи: що входить у процедуру, чим відрізняються варіанти та що уточнити під час запису. FAQ пояснює манікюр з укріпленням і вибір педикюру. Пояснення беруть факти з підтвердженого прайсу, не дублюють фіксовані суми й присутні в серверному HTML. Нових роутів немає.
- Cormorant Garamond і Manrope завантажуються локально як variable WOFF2 з `font-display: swap` та `unicode-range`. Прибрано зовнішній CSS Google Fonts. Джерела та ліцензії SIL Open Font License збережені в [каталозі шрифтів](../src/assets/fonts/README.md); українські символи підтримуються.
- Видалено залежність від Framer Motion. Паралакс на комп’ютері працює через браузерні API лише для видимого першого екрана в активній вкладці; на мобільних і при `prefers-reduced-motion` вимкнений. У порівнянні локальних production-збірок основний JS зменшився з 445 843 до 321 705 байтів без стиснення (приблизно на 28%). Це розмір одного файлу, не прискорення завантаження на 28% і не оцінка позицій у Google.
- Фото першого екрана має варіанти 480, 800 та 1200 px: браузер обирає потрібний через `srcSet` і `sizes`, зберігаючи оригінал для щільних екранів. Локальні заміри та обмеження: [PERFORMANCE.md](PERFORMANCE.md).
- Сім фото галереї мають конкретні описи `alt`, перевірені за зображеннями: колір, форма, дизайн або видимий вигин вій. Рекламні підписи залишаються окремими. Описи присутні в SSR і lightbox, редагуються в адмінці та очищаються при заміні фото. Сумісність зі старими записами забезпечена за шляхом початкового фото без перезапису опублікованих даних. Це допомагає доступності й розумінню зображень, але не гарантує позицій. [Google: опис зображень](https://developers.google.com/search/docs/appearance/google-images#descriptive-alt-text).
- Головна має title, description, canonical, Open Graph / Twitter metadata. JSON-LD пов’язує `BeautySalon`, `WebSite`, `WebPage` і каталог усіх послуг.
- `Offer.price` містить лише однозначні суми; варіанти на зразок `50/70 грн` залишаються текстом. Посилання пропозицій ведуть на `/#services`.
- Robots і sitemap спільні для Express та Worker. Sitemap містить лише `/`; `/index.html` отримує 301 на головну зі збереженням query-параметрів. Невідомі сторінки повертають 404.
- Адмінка виключена з публічного SSR bundle та індексації. Node renderer зберігається поза публічним `dist/`; snapshots містять лише публічні дані й екрануються.

Галерея містить реальні роботи. Населений пункт та адреса беруться з адмінки. ЖК «Софія» є основним локальним акцентом, Вишневе згадується лише як додатковий напрямок приїзду до фактичної адреси у Софіївській Борщагівці. Гарантії, стаж, сертифікати, тривалість процедур і відгуки не вигадуються.

SSR робить початковий контент доступним без виконання JavaScript, але не означає, що Google раніше не міг індексувати сайт. [Google: JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics).

Розмітка допомагає описати бізнес, але не гарантує спеціальний вигляд результату. FAQ залишається видимим корисним контентом; власні відгуки салону не позначаються як рейтинг для отримання зірок. [LocalBusiness](https://developers.google.com/search/docs/appearance/structured-data/local-business), [правила відгуків](https://developers.google.com/search/docs/appearance/structured-data/review-snippet).

Це аудит доступних сторінок і коду, а не звіт із Search Console чи вимірювання позицій.

## Після розгортання

1. Перевірити головну: HTTP 200, актуальні ціни й контакти у вихідному HTML, правильний canonical. Перевірити 301 для `/index.html` і 404 для невідомих сторінок.
2. Власник має доступ до Google Search Console та Google Business Profile. У Search Console перевірити потрібний ресурс, подати `https://victoriya-beauty.space/sitemap.xml`, перевірити головну через URL Inspection, rendered HTML та обраний Google canonical. Прямий доступ агента до цих облікових записів у поточному сеансі не налаштований.
3. Перевірити structured data через Rich Results Test / Schema Markup Validator.
4. Актуалізувати Google Business Profile: реальна назва, телефон, адреса, графік, сайт, перелік послуг і фотографії входу, студії та робіт.
5. Запрошувати реальних клієнтів залишати відгуки без винагороди й відповідати на них. Додати сайт до власного Instagram та перевірених локальних каталогів з однаковими контактами.
6. Перевірити мобільну швидкодію через PageSpeed Insights після публікації. Порівнювати LCP, INP і CLS за польовими даними, коли вони доступні.

Локальний пошук враховує релевантність, відстань і популярність бізнесу. Технічна готовність не замінює Google Business Profile та репутацію. [Google: local ranking](https://support.google.com/business/answer/7091).

## Вимірювання та перевірки

У Search Console зберегти початковий звіт «Ефективність → Результати пошуку» за останні 3 місяці: тип «Веб», країна Україна, покази, кліки, CTR та середня позиція. Аналізувати брендові запити окремо, а небрандові — за трьома пріоритетами й географіями з таблиці; окремо перевірити мобільні пристрої. Після повторного обходу оновленої головної порівнювати рівні 28-денні періоди з урахуванням попиту й сезонності. Середня позиція не означає фіксованого місця для кожного користувача. [Довідка про звіт](https://support.google.com/webmasters/answer/7576553).

Google Business Profile оцінювати окремо: запити профілю, дзвінки, маршрути й переходи на сайт. Ці дані не є звітом про позиції органічного сайту. Контролювати натискання запису й телефону в наявній аналітиці. Відсутність результату у випадковому `site:`-пошуку не вважати доказом відсутності індексації. [Метрики профілю](https://support.google.com/business/answer/9918094).

Позицію №1 визначено як побажання власника, а не обіцяний результат. Код і контент покращують доступність та відповідність запитам; масштаб зміни позицій без даних Search Console невідомий. Для Maps додатково важливі відстань, відповідність профілю й відомість бізнесу, тому згадка Вишневого не замінює фізичну адресу там.

Початкова перевірка публічного HTML 22 вересня 2026, до публікації цих змін: сайт віддавав title «Манікюр · Софіївська Борщагівка | Beauty Space Victoriya», без нового видимого H1 та актуального FAQ про ціну педикюру. Це вихідний стан для перевірки деплою; вплив оновлення на позиції потребує окремого вимірювання після публікації.

Локальні перевірки: `npm run build`, `npm run lint`, `npm run cf:check`, `npm run test:server`, `npm run test:worker` та браузерні тести головної. Вони перевіряють SSR, пояснення послуг із поточним опублікованим прайсом, екранування, відсутність посилань на прибрані сторінки, 404, роботу без JavaScript і hydration. Це перевірка реалізації, не результат індексації Google.

Зміни в репозиторії самі по собі не публікують сайт і не надсилають sitemap до Search Console.
