## Публікація та Google

На момент code commit: код і незалежне рев’ю перевірено; push/deployment/production checks ще не зафіксовані. Результати публікації додаються окремим документаційним комітом після фактичної перевірки.

Немає авторизованого GSC connector/API або доступної керованої browser surface: CUA повернув `CUA_REPL_ENABLED_SURFACES is required`. Discovery знайшов лише непідключені сторонні інтеграції, не наявний офіційний доступ для sitemap submission/Request indexing. Credentials не запитували у відкритому тексті. GSC impressions/clicks/CTR, Google-selected canonical, manual actions/security issues, останній crawl і поточна індексація невідомі; публічний `site:` пошук їх не замінює.

Після справного production власнику потрібен Owner або Full user у наявній property `sc-domain:victoriya-beauty.space` чи URL-prefix `https://victoriya-beauty.space/` (наявність саме цих properties в акаунті без доступу не підтверджено). У Sitemaps перевірити/подати `https://victoriya-beauty.space/sitemap.xml` один раз. URL Inspection → Test live URL → Request indexing: спочатку `https://victoriya-beauty.space/`, потім `/pedicure`, `/laminuvannia-vii`. Зафіксувати прийняття й дату. Indexing API/IndexNow/URL removals не застосовуються для цього завдання. Подання sitemap і запит не є гарантією індексації.

Через 2–4 тижні після crawl перевірити page indexing/selected canonical і останню дату обходу проти дати deployment; порівнювати рівні 28-денні періоди за небрандовими локальними запитами, сторінками та mobile: impressions, clicks, CTR; GBP calls/routes/site visits окремо. Contact clicks не є підтвердженими записами. Реальні звернення/записи звіряє власник, field LCP/INP/CLS оцінювати лише за доступності даних.
